# Phitron — Introduction to Programming

This repository contains my learning journey and practice work from the **Introduction to Programming** course by **Phitron**.

The main goal of this repository is to build a strong foundation in programming by learning fundamental concepts, solving problems, practicing logical thinking, and gradually improving problem-solving skills through hands-on coding.

## 📚 Topics Covered

Throughout this course, I am practicing and learning essential programming concepts, including:

* Introduction to Programming
* Variables and Data Types
* Taking Input and Printing Output
* Integer, Floating-Point and Boolean Values
* Operators and Expressions
* Conditional Statements (`if`, `else if`, `else`)
* Nested Conditions
* Logical and Relational Operators
* Loops (`for`, `while`)
* Loop Control Statements
* `break` and `continue`
* Number-Based Problems
* Digit Extraction using `%` and `/`
* Digit Sum
* Reverse of a Number
* Counting Digits
* Finding Maximum Digit
* Prime Numbers
* Factorial
* Perfect Numbers
* Armstrong Numbers
* Pattern Problems
* Nested Loops
* Problem Solving and Logical Thinking

## 🧩 Problem Solving

A major focus of this repository is **problem-solving practice**. Instead of only learning syntax, I am trying to understand how programming logic works and how to break a problem into smaller steps.

The repository includes practice problems with increasing difficulty, from basic input/output and conditions to loops, number manipulation, nested loops, and challenging logical problems.

## 💻 Language

The problems and solutions in this repository are primarily written in:

**C**

I am focusing on writing simple, readable, and logically correct programs while developing a strong understanding of programming fundamentals.

## 🎯 Goal

The goal of this repository is to document my progress from programming fundamentals to more advanced problem-solving concepts. It will also serve as a personal reference for reviewing concepts, practicing problems, tracking progress, and preparing for future topics such as **Data Structures, Algorithms, Software Development, and Competitive Programming**.

This repository represents my continuous learning process, practice, mistakes, debugging, and improvement as I build a stronger foundation in programming.
